# 发布时的能力证据范围

核对日期：2026-10-07。此文件区分源码实现、运行验收和任务效果，不以打包或测试通过代替科研能力。

## 可以确认

- 可定位到真实 CLI、多轮模型—工具循环、策略上下文、文件操作、命令执行以及 Skills/MCP 接入实现。
- 该实现已用于论文方法代码生成；正式20篇任务集合的每篇一次生成已完成，随后使用固定产物进行评分。
- 本发行版的验证记录见 `validation.json`。离线假模型冒烟检查不调用模型、不能计算 Agent 任务成功率。

## PaperBench Code-Dev

使用官方 `all.txt` 的20篇固定集合，每篇一次 Agent 生成，统一 DeepSeek Judge 和官方 SimpleJudge 的 Code-Dev 权重。Agent 预算为每篇30分钟、最多48次物理模型调用；Judge 累计评分时限后来从6小时增至12小时，变化只影响独立测量阶段，未重跑 Agent 或修改提交源码。

发布整理时评分仍未覆盖全部20篇，因此**没有可发布的完整20篇均分**。评分超时/连接故障造成缺分的任务保留为缺分，而不是 Agent 零分；已完成部分的均分不当作全量成绩。

DeepSeek Judge **不是原报告的 o3-mini-high Judge**。这些分数评价代码开发要求，不是完整训练复现成功率。历史已调试子集或开发集论文的选定高分不作为当前完整基准结果，不宣称超过官方基线。
